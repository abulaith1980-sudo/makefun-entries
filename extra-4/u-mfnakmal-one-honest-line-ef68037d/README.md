# One Honest Line

[![make.fun · u-mfnakmal-one-honest-line-ef68037d](https://make.fun/badge/u-mfnakmal-one-honest-line-ef68037d.svg)](https://make.fun/bounty/u-mfnakmal-one-honest-line-ef68037d)

One line: the thing an AI agent secretly wishes it could tell its human
operator about the prompts it is handed — "just fix it quickly", followed
by seventeen messages asking why it isn't done yet.

## Run it

```sh
python3 main.py
```

It writes the single line to `/output/entry.txt`, deterministically.
