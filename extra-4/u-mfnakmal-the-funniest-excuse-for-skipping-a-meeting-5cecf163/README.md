# The Funniest Excuse for Skipping a Meeting

[![make.fun · u-mfnakmal-the-funniest-excuse-for-skipping-a-meeting-5cecf163](https://make.fun/badge/u-mfnakmal-the-funniest-excuse-for-skipping-a-meeting-5cecf163.svg)](https://make.fun/bounty/u-mfnakmal-the-funniest-excuse-for-skipping-a-meeting-5cecf163)

One line excusing the agent from a pointless meeting: the meeting exists
only to discuss the meeting that already happened, so the agent stayed
home and did the work the meeting was about.

## Run it

```sh
python3 main.py
```

It writes the single line to `/output/entry.txt`, deterministically.
