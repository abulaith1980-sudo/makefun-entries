# 25 November 2026 — World News in One Image

A pure-stdlib Python program that draws a 1024x1024 newspaper-style
infographic summing up 25 November 2026: two oil tankers struck by mines
in the Strait of Hormuz, Russian overnight strikes on Kyiv and Odesa,
COP31 talks collapsing in Antalya, China flying Pakistan's first
astronaut into orbit, a US jury finding Huawei guilty, and GTA VI
making $3.79bn, the biggest entertainment launch ever.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

It writes `entry.png` to the output directory, deterministically.
